# PRD: Soriseom (소리섬)

> 2026-10-29 설계 인터뷰에서 정한 내용입니다. Claude는 `/harness plan` 때 이 문서를 읽고, 각 스텝의 description에 관련 섹션을 "먼저 읽을 파일"로 적습니다.

## 목표

곡이 바뀌면 지금 재생 중인 음악을 화면에 몇 초간 보여주고 사라지는 Windows 앱입니다. Windows 미디어 세션에 정보를 보내는 앱이면 플레이어 종류와 상관없이, 로그인 없이 동작합니다.

## 사용자

- Windows 10/11에서 브라우저(YouTube, YouTube Music)나 Spotify 등으로 음악을 틀어 놓고 다른 작업을 하는 사람
- 창을 전환하지 않고 지금 나오는 곡을 확인하고 싶을 때 씁니다.
- Microsoft Store에서 무료로 설치합니다.

## 핵심 기능

### 1. 곡 변경 팝업

- Windows가 현재 세션으로 정한 세션이 재생 중이고 (제목, 아티스트)가 마지막으로 표시한 곡과 다르면 팝업을 띄웁니다.
- 표시 내용은 제목, 아티스트, 앨범아트입니다. 앨범아트가 없으면 음표 아이콘을 보여주고, 16:9 썸네일처럼 정사각형이 아닌 이미지는 가운데를 정사각형으로 잘라 씁니다.
- 기본 4초 후 사라집니다. 표시 중에 곡이 또 바뀌면 내용을 바꾸고 표시 시간을 처음부터 다시 셉니다.
- 일시정지 상태에서 곡 정보만 바뀌면 띄우지 않고, 그 곡이 재생을 시작할 때 띄웁니다.
- 같은 곡을 반복 재생해서 곡 정보가 그대로면 띄우지 않습니다.
- 브라우저는 제목과 썸네일을 따로 갱신하므로, 짧게 기다렸다가 한 번에 반영합니다. 중간 상태로 팝업이 두 번 뜨지 않아야 합니다.
- 완료 기준: 위 규칙을 Core 단위 테스트로 검증합니다. 실제 앱에서 YouTube Music으로 곡을 넘기면 곡당 팝업이 한 번만 뜹니다.

### 2. 팝업 모양과 동작

- 주 모니터에 띄웁니다. 기본 위치는 위쪽 가운데입니다.
- Windows 11 스타일입니다. Acrylic 반투명 배경에 둥근 모서리를 쓰고 시스템 라이트/다크 테마를 따릅니다. 위에서 미끄러지며 나타나고 페이드로 사라집니다.
- 너비는 고정이고, 긴 제목과 아티스트는 말줄임표로 자릅니다.
- 마우스 클릭은 팝업을 지나 뒤에 있는 창으로 전달됩니다. 팝업은 포커스를 가져가지 않고, 작업 표시줄과 Alt+Tab에 나오지 않으며, 항상 다른 창 위에 뜹니다.
- 내레이터에는 알리지 않습니다.
- 완료 기준: 위쪽 가운데에 팝업이 떠 있는 동안 그 아래 브라우저 탭을 클릭할 수 있고, 입력 중이던 창의 포커스가 유지됩니다.

### 3. 표시하지 않는 경우

- 사용자가 설정에서 끈 앱입니다. 처음 보는 앱은 켜진 상태로 목록에 추가됩니다. 구분은 앱 단위(예: Chrome)이며, 브라우저 안의 사이트는 구분하지 않습니다.
- 전체화면 앱을 쓰는 중입니다. 설정으로 끌 수 있고 기본값은 켜짐입니다.
- Windows 방해 금지 모드가 켜져 있을 때입니다. 안정적으로 감지할 수 있을 때만 적용합니다(`docs/ARCHITECTURE.md` "구현 전에 확인할 것").
- Windows가 현재 세션으로 정하지 않은 세션의 변화(예: 백그라운드 탭)입니다.

### 4. 설정 창

| 항목 | 값 | 기본값 |
|---|---|---|
| 앱별 켜기/끄기 | 지금까지 감지된 앱 목록 | 새 앱은 켜짐 |
| 표시 시간 | 2~10초, 1초 단위 슬라이더 | 4초 |
| 위치 | 위/아래 × 왼쪽/가운데/오른쪽 (6곳) | 위쪽 가운데 |
| 전체화면일 때 숨기기 | 켜기/끄기 | 켜짐 |
| 언어 | 시스템 / 한국어 / English | 시스템 |
| 로그인 시 자동 실행 | 켜기/끄기 | 켜짐 |

- 바꾼 설정은 저장 버튼 없이 바로 저장되고 적용됩니다(Windows 설정 앱과 같은 방식). 언어 변경이 재시작 없이 반영되지 않으면 재시작이 필요하다고 안내합니다.

### 5. 상주

- 트레이 아이콘을 왼쪽 클릭하면 설정 창이 열리고, 오른쪽 클릭하면 메뉴(설정, 종료)가 나옵니다.
- 설정 창을 닫아도 앱은 트레이에 남습니다. 종료는 트레이 메뉴에서만 합니다.
- 단일 인스턴스입니다. 이미 실행 중일 때 다시 실행하면 기존 인스턴스의 설정 창이 열립니다.
- 처음 실행하면 설정 창을 엽니다. 로그인 시 자동 실행될 때는 창 없이 트레이에만 있습니다.

### 6. 현지화

- UI는 한국어와 영어를 지원하고, 기본은 Windows 표시 언어를 따릅니다. 곡 정보는 받은 그대로 표시합니다.

## 범위 밖

- 재생 조작(재생/일시정지, 이전/다음 곡): 표시 전용 앱으로 단순하게 유지합니다.
- 진행 바, 재생 시간, 앨범명, 재생 중인 앱 표시: 몇 초짜리 팝업에는 필요 없습니다.
- 곡 변경 외의 트리거(트레이 클릭, 전역 단축키, 재생 재개, 앱 시작 시 표시): 사용자가 원하지 않았습니다.
- 서비스별 API(Spotify Web API 등)와 로그인: GSMTC로 앱 구분 없이 지원합니다.
- macOS, Linux: Windows 전용입니다.
- 방송 오버레이(OBS), 드래그로 자유 배치, 흐르는 글자(마키), 내레이터 알림: 사용자가 선택하지 않았습니다.
- 브라우저 안의 사이트별 필터: GSMTC가 앱 단위 정보만 줘서 기술적으로 불가능합니다.
- 텔레메트리, 크래시 수집, 로그 파일: 데이터를 수집하지 않습니다. 디버그 출력만 씁니다.
- GitHub Releases, winget, 설치 프로그램 배포: Microsoft Store 전용입니다.
- 전용 전체화면(exclusive fullscreen) 게임 위 표시: 기술적으로 불가능합니다.

## 제약

- Windows 10 1809(10.0.17763) 이상, Windows 11
- MSIX 패키지 앱이며 Microsoft Store 정책을 지킵니다.
- 네트워크를 쓰지 않습니다. 곡 정보는 PC 밖으로 나가지 않습니다.
- 무료, MIT 라이선스, 공개 저장소 `LOONACIA/Soriseom`
- 작업을 방해하지 않습니다. 포커스를 가져가지 않고 클릭은 통과합니다.
